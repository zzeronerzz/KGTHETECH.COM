What's an MCP server?

Model Context Protocol (MCP) is the open spec for giving LLMs structured access to your tools and data. An MCP server is a small process the client (Claude Desktop, Cursor, etc.) spawns and talks to over stdio. Each server exposes a set of tools the LLM can call by name.

How to install

unzip mcp-<name>.zip
cd mcp-<name>
npm install

Then add to your claude_desktop_config.json (or Cursor MCP settings):

{
  "mcpServers": {
    "mcp-cantenna-calc": {
      "command": "node",
      "args": ["/absolute/path/to/mcp-cantenna-calc/server.js"]
    }
  }
}

Restart your client. The tools become available in chat.
